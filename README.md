# Euroccat

Thème WordPress du site de l'association Euroccat (pays occitans et pays catalans).

## Installation

1. Copier le dossier dans `wp-content/themes/euroccat`.
2. Activer le thème dans Apparence > Thèmes.
3. Réglages > Lecture : choisir une page d'accueil statique et une page pour les articles.
4. Créer les menus dans Apparence > Menus (emplacements : principal, pied de page, liens légaux).

## Réglages

Apparence > Personnaliser > Thème Euroccat : couleurs, textes de l'accueil, frise des rencontres, coordonnées, réseaux sociaux, pied de page.

Modèles de page disponibles :

- Bibliothèque de documents : liste les PDF de la médiathèque, avec recherche et filtre par année.
- Contact : coordonnées et formulaire (les messages partent à l'adresse indiquée dans les réglages).
- Pleine largeur : page libre, sans bandeau.

## Police

Le thème utilise Gilroy. Les fichiers ne sont pas fournis (licence payante) : les placer dans `assets/fonts/` (voir `assets/fonts/LISEZ-MOI.txt`). Sans eux, la police Urbanist est chargée à la place.
